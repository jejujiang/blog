title: Femotlisp

Femtolisp（常写作 femtoLisp）的名字含义是“极小的 Lisp”。

它的命名源自单位 “飞米” (Femto-)，代表 10^{-15}，寓意其极致轻量和紧凑的设计目标。具体量化来看：

· 代码量极小：诞生之初的目标是在 1000 行 C 代码内实现一个高效的 Lisp 解释器。
· 核心极简：整个语言的核心仅包含 12 个内置特殊形式和 33 个内置函数。

这个项目由 Jeff Bezanson 开发，后来作为Julia语言的早期解析器和前端被广泛使用。

结合你之前问的Femtolisp，这里的“飞米”就是它的词根。我来为你讲解一下这个长度单位。

飞米是一个极小的长度单位，符号是 fm。

· 大小：1飞米等于 10^{-15} 米，也就是小数点后跟14个零，最后是1。
· 比例感：如果把1米比作地球的直径，那么1飞米大约相当于一根头发丝粗细的十万分之一。或者更直观地，1飞米 : 1米 = 1 : 1千万亿。

它在哪里使用？

飞米几乎专用于原子核物理和粒子物理领域，用来测量原子核内部的世界。

· 质子或中子的直径大约就是 1.6 飞米。
· 原子核（比如铀核）的直径在几飞米到十几飞米之间。
· 两个核子之间的距离也在飞米量级。

命名和背景

· 名字来源：源自丹麦语“femten”，意思是“十五”，对应 10^{-15} 这个因子。
· 所属体系：它是国际单位制（SI）中的正式长度单位，属于“米”的分数单位系列。这个系列常用词头从大到小包括：米 (m) → 毫米 (mm, 10^{-3}) → 微米 (μm, 10^{-6}) → 纳米 (nm, 10^{-9}) → 皮米 (pm, 10^{-12}) → 飞米 (fm, 10^{-15})。
· 曾用名：过去也叫做“费米”（Fermi，符号F），以纪念物理学家恩里科·费米。这个名字现在虽不官方，但仍在一些场合使用。

用它来理解Femtolisp

现在你就能理解 Femtolisp 这个名字的精妙之处了：它寓意这是一个 “原子核级别”微小 的Lisp方言。就像飞米用来描述质子的大小一样，Femtolisp的设计目标就是在极小的代码体积内实现一个功能完整的Scheme语言。

Femtolisp 的 12 种特殊形式如下：

1. quote - 返回参数本身，不进行求值
2. if - 条件分支 (if cond then else)
3. cond - 多分支条件判断
4. lambda - 创建匿名函数
5. macro - 定义宏
6. label - 为函数定义内部名称（用于递归）
7. and - 短路逻辑与
8. or - 短路逻辑或
9. set - 为已有变量赋值
10. progn - 顺序执行，返回最后一个值
11. prog1 - 顺序执行，返回第一个值
12. while - 循环

Femtolisp 的 33 个内置函数如下：

类型判断 (8个)

1. eq - 指针相等比较
2. atom - 判断是否为原子
3. symbolp - 判断是否为符号
4. numberp - 判断是否为数字
5. boundp - 判断符号是否绑定
6. consp - 判断是否为 cons 单元
7. listp - 判断是否为列表
8. functionp - 判断是否为函数

列表操作 (6个)
9.  cons - 构造 cons 单元
10. car - 取列表头部
11. cdr - 取列表尾部
12. rplaca - 破坏性修改 car
13. rplacd - 破坏性修改 cdr
14. nth - 取第 n 个元素

运算与比较 (6个)
15. + - 加法
16. - - 减法/取负
17. * - 乘法
18. / - 除法
19. < - 小于比较
20. = - 数值相等比较

交互与环境 (8个)
21. read - 读取表达式
22. print - 打印值
23. eval - 执行代码
24. apply - 应用函数于参数列表
25. load - 加载并执行文件
26. error - 抛出错误
27. exit - 退出解释器
28. gc - 强制执行垃圾回收

类型转换 (5个)
29. str - 转字符串
30. number - 转数字
31. symbol - 转符号
32. list - 转列表
33. vector - 创建或转向量

注：不同版本可能有细微差异，部分函数（如 list、vector、nth）在某些实现中可能通过标准库提供而非纯内置。
